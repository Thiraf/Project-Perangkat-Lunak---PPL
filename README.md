## 🚀 Setup Project DOKI

Follow these steps to run the project locally:

## Clone Repository

To deploy this project run

```bash
git clone <repo-url>
cd <nama-folder-project>
```

## Install Dependency Laravel

To deploy this project run

```bash
  composer install

```

## Setup Environment

To deploy this project run

```bash
cp .env.example .env
php artisan key:generate

```

## Install Dependency Frontend

```bash
npm install
npm install dayjs


```
